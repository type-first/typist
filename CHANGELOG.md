# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-11-04

### Added
- Initial release of @typefirst/typist
- Phantom type utilities for zero-runtime type manipulation
- Type assertion utilities for static testing
- Verdict encoding system for type comparison results
- Static comparators for type relationships (`$Equal`, `$Extends`)
- Test block utilities for type-level unit testing
- Comprehensive TypeScript type-level toolkit
- ESM module support with full TypeScript integration
- Professional README with examples and API documentation

### Features
- 🎭 **Phantom Types** – Runtime-zero type value creation
- 🔍 **Type Assertions** – Static type relationship testing  
- ⚖️ **Verdict Encoding** – Rich error reporting for type comparisons
- 🧩 **Symbolic Inference** – Type manipulation as first-class operations
- 🚀 **Zero Runtime** – Pure compile-time operations
- 📦 **ESM Ready** – Modern module system support
